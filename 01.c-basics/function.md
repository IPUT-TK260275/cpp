# 01：入力・計算・表示

この章の `.cpp` では、`scanf` で入力し、`printf` で表示します。

## 数値を入力する

```cpp
int n;
scanf("%d", &n);       // 整数を読み取って n に入れる

double x;
scanf("%lf", &x);     // 小数を読み取って x に入れる
```

`&n` の `&` は「入力先はこの変数」という指定です。

## 値を表示する

```cpp
printf("Hello\n");   // 文字を表示する。\n は改行
printf("%d\n", n);   // 整数を表示する
printf("%g\n", x);   // 小数を表示する
```

| 扱う値 | 入力の書式 | 表示の書式 |
| --- | --- | --- |
| `int`（整数） | `%d` | `%d` |
| `double`（小数） | `%lf` | `%g` |
| `long long`（大きな整数） | — | `%lld` |

`printf("%.6f\n", x);` とすると、小数点以下を6桁で表示できます。

## 計算する

| 書き方 | 意味 | 例 |
| --- | --- | --- |
| `+` | 足す | `2 + 3` → `5` |
| `-` | 引く | `5 - 2` → `3` |
| `*` | 掛ける | `2 * 3` → `6` |
| `/` | 割る | `7 / 2` → `3`、`7.0 / 2` → `3.5` |
| `%` | 整数の割り算の余り | `7 % 2` → `1` |

整数同士の割り算では、小数部分がなくなります。

```cpp
int a = 3;            // 変数を作り、3を入れる
int b = 5;
double mean = (a + b) / 2.0;
a = 10;               // a の値を変更する
```

## 条件で分ける

```cpp
if (a == b) {         // a と b が等しいとき
    printf("EQUAL\n");
} else {              // 等しくないとき
    printf("NOT-EQUAL\n");
}
```

`=` は値を入れる記号、`==` は等しいかを調べる記号です。大小の比較には `>`、`>=`、`<=` も使っています。

## 繰り返す

```cpp
for (int i = 1; i <= 5; i++) {
    printf("%d\n", i); // 1〜5を順に表示する
}
```

`for` の括弧は「最初の値; 続ける条件; 1回ごとの更新」の順です。`i++` は1増やすという意味です。

```cpp
while (scanf("%lf", &x) == 1) { // 数値を読み取れた間、繰り返す
    if (x == 0) {
        break;                 // 繰り返しを終える
    }
}
```

`sum += x;` は `sum = sum + x;` の短い書き方です。

## JavaScript版との対応

| C/C++ | JavaScript |
| --- | --- |
| `scanf("%lf", &x);` | `let x = Number(Lib.input());` |
| `printf("%g\n", x);` | `Lib.print(x); Lib.print("\n");` |
| `a == b` | `a === b` |
