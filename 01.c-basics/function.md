# 01 — C言語の基礎：関数・構文一覧

このフォルダーの `.cpp` と `.js` で実際に使っている関数・構文をまとめています。`.cpp` の例はC形式の標準入出力を使います。リンク先で使用例を確認できます。

## C形式の関数

| 関数 | 用途・記述例 | 使用ファイル |
| --- | --- | --- |
| `main` | プログラムの開始点。`int main(void) { ... }` | [1.7.E1.cpp](1.7.E1.cpp) |
| `scanf` | 標準入力から値を読み取る。`scanf("%lf", &a);`。返り値は読み取って代入できた項目数 | [1.7.E1.cpp](1.7.E1.cpp)、[1.7.A1.cpp](1.7.A1.cpp) |
| `printf` | 書式を指定して標準出力へ表示する。`printf("%g\n", mean);` | [1.7.E1.cpp](1.7.E1.cpp) |

### 入出力の書式

| 書式・記号 | 意味 | 使用例 |
| --- | --- | --- |
| `%d` | `int` の読み取り・表示 | `scanf("%d", &n);` / `printf("%d\n", n);` |
| `%lf` | `scanf` で `double` を読み取る | `scanf("%lf", &value);` |
| `%g` | `printf` で実数を通常表記または指数表記で表示する | `printf("%g\n", mean);` |
| `%.6f` | `printf` で実数を小数点以下6桁で表示する | `printf("> %.6f\n", sum / count);` |
| `%lld` | `long long` を表示する | `printf("%lld\n", k * k);` |
| `\n` | 改行 | `printf("---\n");` |
| `&変数` | 入力先の変数のアドレスを渡す | `scanf("%d", &n);` |

`scanf` で実数を読む `%lf` と、`printf` で実数を表示する `%g`・`%f` を区別します。
